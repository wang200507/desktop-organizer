# Desktop Organizer（桌面图标整理工具）

一个类 cooDesker / Fences 的 Windows 桌面图标自动整理工具。用 **Rust** 编写，基于 **GDI + 分层窗口（WS_EX_LAYERED）** 渲染半透明分区卡片，把桌面图标按类型自动归档到可自由拖拽的卡片中。

**核心卖点：极低内存** —— 常驻私有内存约 **9MB**，exe 仅约 **200KB**，后台运行几乎无感。

## 功能特性

| 功能 | 说明 |
|------|------|
| 自动扫描分类 | 扫描桌面快捷方式/文件，按 应用/文件夹/文档/图片/其他 自动分组 |
| 半透明分区卡片 | GDI + 分层窗口 per-pixel alpha，无 Direct2D 驱动栈开销 |
| 卡片自由拖拽 | 按住标题栏拖动移动；右/下边缘调整大小；拖动自动置顶 |
| 样式切换 | 网格图标模式 / 列表模式（可滚动、滚动条指示） |
| 位置记忆 | 位置与尺寸持久化到 `layout.json`，重启自动恢复 |
| 双击隐藏 | 双击桌面空白隐藏/显示卡片（全局钩子检测） |
| 一键归位 | F5 重排回默认布局 |
| 原生桌面右键 | 桌面空白右键弹出系统原生菜单（Shell COM），卡片内右键弹自定义菜单 |
| 桌面接管 | 隐藏系统图标层，卡片显示在壁纸之上、正常窗口之下 |
| 异常兜底 | watchdog 守护子进程：程序被强杀后自动恢复桌面图标 |
| 设置界面 | F1 打开：透明度 / 背景色 / 显示格式 / 卡片大小 / 自动分类等 |

## 技术方案（低内存核心）

```
Rust 原生码（无 GC/VM，静态链接 CRT）
  └─ GDI 纯软件渲染
       └─ WS_EX_LAYERED 分层窗口 + UpdateLayeredWindow(ULW_ALPHA | AC_SRC_ALPHA)
            └─ 32 位 DIB per-pixel alpha 半透明圆角卡片
                 └─ 窗口跟随卡片包围盒，增量合成（避免全屏合成卡顿）
```

**为什么不用 Direct2D**：实测 Direct2D 需加载 d3d11/dxgi/d2d1/dwrite 整套 GPU 驱动栈，私有内存 **46MB**（超标 3 倍）；而 GDI + 分层窗口仅 **9MB**，同样能实现半透明圆角。这是 Fences/cooDesker 类工具的实际做法。

**为什么不用 Electron/WPF/Java**：解释器/运行时起步 50~200MB，直接出局。

## 实测性能

| 指标 | 实测值 |
|------|--------|
| 私有内存（常驻） | **~9 MB**（目标 <15MB） |
| exe 体积 | **~200 KB**（release: opt-level z + lto + strip） |
| 渲染方式 | GDI 软件渲染（不加载 GPU 驱动栈） |

## 构建

环境要求：Rust stable MSVC 工具链 + VS Build Tools（C++ 工作负载 + Windows SDK）。

```bash
cargo build --release
```

产物：`target/release/desktop-organizer.exe`

## 运行与操作

```bash
desktop-organizer.exe
```

| 操作 | 效果 |
|------|------|
| 拖拽卡片标题栏 | 移动卡片 |
| 拖拽卡片右/下边缘 | 调整卡片大小 |
| 双击桌面空白 | 隐藏/显示所有卡片 |
| 点卡片右上角 × | 删除该分区 |
| 点标题栏 ▦ / ≡ | 切换 网格图标 / 列表 模式 |
| 鼠标滚轮 | 滚动卡片内容 |
| F5 | 一键归位（重排默认布局） |
| F1 | 设置界面 |
| Esc | 退出（自动恢复系统桌面图标） |
| 卡片内右键 | 删除分区 / 新建分区 / 设置 / 退出 |
| 桌面空白右键 | 系统原生菜单（查看/排序/刷新/新建/显示设置…） |

## 模块结构

```
src/
├── scanner.rs   桌面扫描与分类（图标获取、.lnk 解析去箭头）
├── layout.rs    分区模型、布局、命中测试、JSON 持久化
├── renderer.rs  分层窗口渲染（GDI + UpdateLayeredWindow）
├── settings.rs  配置结构（透明度/背景色/显示格式等）
└── main.rs      窗口、事件交互、全局鼠标钩子、watchdog
```

## 兼容性

- Windows 10 / Windows 11（x64）
- 多显示器：主屏桌面接管 + 副屏保留系统原生行为

## 已知说明

- 图标显示模式会解析 `.lnk` 指向目标的真实图标（去除快捷方式小箭头）
- `layout.json` / `settings.json` 为运行时生成的用户数据，位于 exe 同目录，删除即恢复默认布局
